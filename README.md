# 🛒 Fake Store Flutter App

A Flutter shopping application that fetches products from the Fake Store API and displays them with a modern UI.

## 📱 Features

- ✅ Fetch products from REST API
- ✅ Display product list
- ✅ Product details screen
- ✅ Hero image animation
- ✅ Product image loading & error handling
- ✅ Show product price, category, rating, and description
- ✅ Modern Material 3 UI
- ✅ Add to Cart button UI

## 🚀 Technologies Used

- Flutter
- Dart
- REST API
- HTTP Package
- Material 3 Design
